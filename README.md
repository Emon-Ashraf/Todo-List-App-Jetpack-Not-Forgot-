# Not Forgot · Android To-Do List

An Android task manager built with Kotlin and Jetpack Compose. It lets users organize tasks with descriptions, deadlines, and priorities.

## Features

- Add, open, edit, and delete tasks.
- Mark tasks as completed.
- Keep task state in memory through a ViewModel and repository.

## Getting Started

Open the project in Android Studio with JDK 17 and Android SDK 34. Sync Gradle and run the `app` configuration on an emulator or device running Android 7.0 (API 24) or later. Tasks reset when the app process ends.
